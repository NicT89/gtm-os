# Examples

Format anchors for the skills. Each file shows the *shape* of an output the skills
describe in prose, so a run has something concrete to match.

| File | Anchors |
|---|---|
| `scan-report.md` | gtm-signal-scan step 7 |
| `audit-log-entry.md` | the audit-log append every skill ends with |
| `blueprint-hiring.md` | gtm-blueprint step 4 output, hiring motion |

## These are synthetic

Every company, person, number, and URL in this folder is invented for illustration.
No file here contains real prospect data, and none should ever be edited to add any:
real run artifacts live in the operator's own storage, never in this repo.

They are written to be *structurally* faithful — the right sections, the right level
of specificity, the falsifiability test passing — while being obviously fictional on
inspection. Domains use `.example`, which is reserved and cannot be registered.

When the format changes, update these alongside the skill, or they quietly become
the wrong target.
